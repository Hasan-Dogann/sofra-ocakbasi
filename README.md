# Sofra Ocakbaşı

Kağızman, Kars'taki Sofra Ocakbaşı için mobil uyumlu restoran sitesi.

## Yerelde çalıştırma

Node.js 18 veya üzeri ile:

```sh
npm run dev
```

Adres: http://127.0.0.1:5180/

Harici paket kurulumu gerekmez. Site dosyaları `dist` klasöründedir.

## İçerik

Ana sayfa, Soframız, Hakkımızda, Lezzetler ve İletişim sayfaları bulunur.
Menü 7 kategoride 50 ürün içerir. Fiyatlar yayımlanmaz; günlük ürün bulunabilirliği ve fiyatlar için iletişim bilgisi gösterilir.

## Yayın

Statik hosting için yayın klasörü `dist`, derleme komutu yoktur.
Seçilen alan adı: `sofraocakbasi.com`. Satın alma ve DNS bağlantısı ayrıca tamamlanmalıdır.
Alan adı kesinleşip yayınlanırken `SEO-YAYIN.md` adımlarını uygulayın.

Kategori görselleri temsilidir. İşletme görselleri, video ve tanıtım dosyaları bu site kapsamında kullanılır.
